# Maple Lane — Gemini instructions

Follow the "Gemini only" section of AGENTS.md. In short:

- Push all work to the `gemini` branch. Never push to `main` or `test`.
- Update `gemini` from `main` before starting new work.
- Claude reviews `gemini` and moves it into `main`; don't merge into `main` yourself.
- Run `node --test` before pushing. Only CC0 / CC-BY assets, no real brand logos.
